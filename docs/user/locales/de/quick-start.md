# Schnellstart

1. Mit **File → Import MVR...** können Sie [ein MVR öffnen](opening-mvr-files.md). Alternativ erstellen Sie ein neues Projekt und fügen Szenenelemente hinzu. [Aus Text erstellen](create-from-text.md) erzeugt eine Ausgangsszene aus einem Rider.
2. Prüfen Sie Platzierung und Ausrichtung in den [2D- und 3D-Ansichten](views.md).
3. Öffnen Sie bei Bedarf den schreibgeschützten [MVR / GDTF-Inspektor](inspector.md), um Paketinhalt und Scheinwerferdefinitionen zu untersuchen.
4. Prüfen und bearbeiten Sie die Tabellen **Fixtures**, **Trusses**, **Hoists** und **Objects**. Kontrollieren Sie Scheinwerfertypen, DMX-Modi, Patch und Positionen.
5. Speichern Sie Ihre Arbeit als `.pstg`-Projekt, um später weiterzuarbeiten.
6. [Exportieren Sie MVR](opening-mvr-files.md#mvr-exportieren) zum Austausch oder erstellen Sie [Layouts und PDF](layouts.md) zum Drucken und Teilen.

Fehlende Profile behandelt [GDTF-Download](gdtf-download.md). Die [Einstellungen](preferences.md) beschreiben Einheiten und Importoptionen; bei Laufzeitproblemen siehe [Fehlerbehebung](troubleshooting.md).
