# 打开 MVR 文件

## 打开或导入

使用 **File → Import MVR...** 并选择：

- **Open as new project**：完成通常的未保存项目检查后，替换场景。
- **Merge into current project**：添加内容并保留现有工作。

在启动时或通过受支持的操作系统文件关联直接打开 `.mvr`，会将其作为新项目打开。取消导入选择不会改变当前项目。

在 [2D/3D](views.md) 和 Fixtures、Trusses、Hoists、Objects 表格中检查导入的场景。使用 [Inspector](inspector.md) 可查看包内容而不导入。

## 合并冲突

UUID 冲突时，可为导入对象生成新 UUID（默认选项，保留两个场景）、替换项目中匹配的对象，或跳过冲突的导入对象。

如果同一灯具类型名称对应不同的 GDTF 定义或模式，可选择当前项目的定义、为导入的定义重命名类型并保留，或取消合并。取消或合并失败会恢复当前项目。

重复的 DMX 地址会在 Console 中产生警告，但不会阻止合并。合并后应检查并修正地址分配。

## 资源与项目存储

导入的 GDTF、符号和模型会保留在项目资源中，以便保存并重新打开后仍可找到。导出前检查缺失的配置文件和模式；参阅[下载 GDTF](gdtf-download.md)和[故障排查](troubleshooting.md)。

将工作保存为 `.pstg`，可保留 Perastage 项目上下文、版面和项目符号。MVR 用于数据交换。Perastage 将自身的交换元数据存储在兼容标准、由应用管理的 UserData 中；其他应用可能不保留这些元数据。

支持的灯具、桁架、吊挂设备和场景对象会保留导入的 FixtureID、FixtureIDNumeric 和 UnitNumber，包括零值、重复值以及可选 UnitNumber 的存在状态。复制和合并不会自动重新编号。超出支持的整数范围会阻止项目保存和导出；请保留源文件。仍可显式修改编号。

## 导出 MVR

1. 选择 **File → Export MVR...**。
2. 选择目标位置；如果项目有名称，建议的文件名会使用该名称。
3. 导出并在接收应用中检查结果。

[偏好设置](preferences.md#mvr-导入--导出)提供桁架几何体兼容选项。保存在 PSTG 中的项目符号不会导出到 MVR 或嵌入的 GDTF 中。

普通导出始终使用规范 MVR；对于相同的场景状态，其内容与 PSTG 中保存的 `scene.mvr` 一致。若要生成替代文件，请在导出对话框中启用**对此文件使用兼容性导出**，然后选择表示方式。保存的首选项仅提供建议，不会自动启用兼容性导出。直接 Geometry3D 会展开桁架的 Symbol/Symdef 引用，而不会修改项目场景或其标识符。
