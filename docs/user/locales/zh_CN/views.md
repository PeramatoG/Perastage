# 视图

用 3D 检查空间关系和朝向，用 2D 检查平面图、位置和可读性。从 **View** 显示隐藏的查看器窗格。

## 导航与检查

在 3D 中，拖动以环绕，Shift 拖动或中键拖动以平移，滚轮以缩放。右键选择 **Render style** 可更改显示方式，包括按类型、图层或 DMX 域着色。

在 2D 中，拖动空白区域以平移，滚轮以缩放。选择场景元素可核对 Fixtures、Trusses、Hoists 和 Objects 中对应的行。在多选状态下双击单元格，可编辑所选各行的该列。

## 移动与选择

- **Drag Move** 允许用左键拖动场景选择，默认关闭。
- **Axis Lock** 限制移动方向。关闭后可在 2D 中自由移动，或在 3D 中沿面向摄像机的平面移动。
- **Local Axes** 更改查看器变换轴。
- **Magnet** 在移动或插入时吸附到兼容锚点。
- **Cross-table Actions** 允许查看器工具操作当前表格之外的对象类型，默认关闭。

组移动遵循[选择与移动偏好](preferences.md#选择与移动)。在两个视图中检查最终位置，必要时使用 Undo。

键盘、鼠标和 Console 输入说明见[快捷键与命令栏](shortcuts-and-command-bar.md)。制作打印页面请使用 [Layouts 与 PDF](layouts.md)。
