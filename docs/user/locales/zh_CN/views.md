# 视图

用 3D 检查空间关系和朝向，用 2D 检查平面图、位置和可读性。从 **View** 显示隐藏的查看器窗格。

## 导航与检查

在 3D 中，拖动以环绕，Shift 拖动或中键拖动以平移，滚轮以缩放。右键选择 **Render style** 可更改显示方式，包括按类型、图层或 DMX 域着色。

在 2D 中，拖动空白区域以平移，滚轮以缩放。选择场景元素可核对 Fixtures、Trusses、Hoists 和 Objects 中对应的行。在多选状态下双击单元格，可编辑所选各行的该列。

## 位置工具

在 2D 或 3D 工作区中打开 **View → Position Tool**。同一个面板可以停靠、浮动、调整大小或隐藏；位置和可见性随工作区保存。未选择对象时，坐标字段禁用。

X、Y 和 Z 输入框在高度紧凑的面板中共享一行，并按可用宽度调整。

面板默认显示在 2D 和 3D 工作区右侧 Summary 下方。每个坐标轴旁的箭头按次移动所有有效目标：公制为 1 毫米，英制为 0.01 英尺，同时保留不同坐标之间的差值及存储精度。每次点击都可撤销。

X、Y 和 Z 表示插入点的绝对世界坐标。编辑一个字段后按 Enter 或离开该字段即可应用；其他坐标轴、旋转和缩放保持不变。Escape 取消尚未提交的编辑。每次完成的编辑对应一个撤销步骤。无效或空白输入不会移动对象。

多选时，共同坐标正常显示，不同的坐标留空。输入数值会将每个有效目标的该轴分别设为同一绝对坐标。组内子对象遵循**Selection & Movement**首选项。组目标使用自身的插入点，所有成员一起移动。

交互式 2D 查看器的顶视、底视、前视和侧视中，用红色小方块标出有效插入点。方块在屏幕上的大小保持不变，不会出现在截图、打印布局或导出中。3D 中不显示这些标记。

距离单位遵循**Preferences → Units**：米默认保留三位小数，英制使用现有的英尺格式。支持单位后缀及英尺/英寸输入。显示舍入不会改变存储的位置。

## 移动与选择

- **Drag Move** 允许用左键拖动场景选择，默认关闭。
- **Axis Lock** 限制移动方向。关闭后可在 2D 中自由移动，或在 3D 中沿面向摄像机的平面移动。
- **Local Axes** 更改查看器变换轴。
- **Magnet** 在移动或插入时吸附到兼容锚点。
- **Cross-table Actions** 允许查看器工具操作当前表格之外的对象类型，默认关闭。

组移动遵循[选择与移动偏好](preferences.md#选择与移动)。在两个视图中检查最终位置，必要时使用 Undo。

键盘、鼠标和 Console 输入说明见[快捷键与命令栏](shortcuts-and-command-bar.md)。制作打印页面请使用 [Layouts 与 PDF](layouts.md)。
