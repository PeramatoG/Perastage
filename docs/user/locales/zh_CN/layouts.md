# Layouts 与 PDF

版面将场景视图和辅助信息组织成可打印的页面。

## 准备页面

1. 打开 **View → Layout Views → Layout Mode View**。必要时从 **View** 显示 **Layouts** 面板。
2. 选择版面，或用 **Add** 新建。**Rename** 和 **Delete** 用于管理页面；最后一个版面不能删除。
3. 使用版面的右键菜单选择方向。
4. 从 Layout 工具栏添加元素：

| 操作 | 内容 |
| --- | --- |
| **Add 2D View** | 2D 场景视图 |
| **Add Legend** | 灯具图例 |
| **Add Event Table** | 活动信息 |
| **Add Text** | 注释和标题 |
| **Add Image** | 标志等图像 |

编辑各元素的可用设置，选择内容和显示方式。生成文档前，应在[视图和表格](views.md)中检查场景数据。

## 排列与编辑

拖动边框以移动，拖动边框控制点以调整大小。双击边框以编辑元素。右键提供编辑、删除和堆叠顺序控制。拖动空白区域以平移，滚轮以缩放。**Z** 将版面适配到视图；**Delete** 删除所选版面元素。

保存 `.pstg` 项目以保留版面。**Export template** 创建包含引用图像的便携 `.pslayout` 包。**Import template** 接受 `.pslayout` 和旧版 `.json` 模板。

## 导出 PDF

选择有内容的版面并使用 **File → Print Layout...**。选择可写的 `.pdf` 目标位置。PDF 使用所选版面的纸张尺寸和方向，并包含支持的元素。打印或分享前请检查导出的文件。

视图缺失、输出错误或导出失败时，请参阅[故障排查](troubleshooting.md#版面与-pdf-问题)。

## 物理比例与视口属性

双击二维视图并打开**视口属性**。新视图和旧文件默认仍使用**自由 / 可变**模式，保留缩放、平移和自动取景。近似有效比例仅供参考。**Visual framing** 滑块调整可视取景，不表示物理比例。

显式选择**固定**可使用 1:25、1:50、1:100、1:200、1:500，或输入 0.01 至 10000000 的自定义分母。场景中一米在 1:50 时占纸面 20 mm，在 1:100 时占 10 mm。中心以米为单位，俯视使用 X/Y，前视使用 X/Z，侧视使用 Y/Z；侧视画面水平正方向为 −Y，数值中心仍为世界 Y。可输入中心，也可在可视编辑器中取景后选择**使用可视取景中心**。接受编辑后，布局预览显示固定比例裁剪区域。

页面 X/Y、边框宽度和高度以毫米显示，原点为左上角，并保留小数精度。允许部分超出页面。最小尺寸为 1 点（约 0.353 mm），位置及尺寸限制为 200000 点。移动或调整固定边框保持中心和比例，只改变可见区域。布局缩放和 DPI 只影响显示。切回自由模式保留先前相机、过滤器和显示设置。**Cancel** 放弃草稿，**OK** 确认；支持撤销/重做和 PSTG/PSLAYOUT 持久化。

页面右键菜单可选 A3/A4 及方向，不缩放内容。含固定视口的页面必须按布局纸张尺寸以 100% 导出 PDF；其他尺寸会被拒绝并说明原因。如需其他纸张，请先修改布局纸张。自由页面仍支持等比适配输出。打印 PDF 时选择实际大小/100%；Perastage 无法控制打印驱动缩放。物理比例保证几何尺寸，不扩展现有字体排版和样式的一致性保证。
