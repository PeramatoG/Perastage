# 快速入门

1. 使用 **File → Import MVR...** [打开 MVR](opening-mvr-files.md)，或新建项目并添加场景元素。[Create from text](create-from-text.md) 可将演出技术需求清单转换为初始场景。
2. 在 [2D 和 3D 视图](views.md)中检查位置和朝向。
3. 按需打开只读的 [MVR / GDTF Inspector](inspector.md)，查看包内容和灯具定义。
4. 检查并编辑 **Fixtures**、**Trusses**、**Hoists** 和 **Objects** 表格，核对灯具类型、DMX 模式、地址分配和位置。
5. 将工作保存为 `.pstg` 项目，以便继续编辑。
6. [导出 MVR](opening-mvr-files.md#导出-mvr) 用于数据交换，或制作 [Layouts 与 PDF](layouts.md) 用于打印和分享。

缺少配置文件时，请参阅[下载 GDTF](gdtf-download.md)。单位和导入设置见[偏好设置](preferences.md)，运行问题见[故障排查](troubleshooting.md)。
