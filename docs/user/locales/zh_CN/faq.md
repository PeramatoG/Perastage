# 常见问题

## Perastage 是实时 DMX 可视化工具吗？

不是。它专注于场景编辑、MVR 检查和技术文档。参阅[功能概览](features.md)。

## PSTG 与 MVR 有什么区别？

PSTG 保留 Perastage 项目上下文、版面和项目符号，便于继续编辑。MVR 用于与其他应用交换场景数据。参阅[打开 MVR 文件](opening-mvr-files.md)。

## 支持哪些桌面平台？

Windows、macOS 和 Linux。参阅[安装](installation.md)及所用版本提供的软件包。

## Perastage 可以导入和导出 MVR 吗？

可以，包括作为新项目打开或合并到当前项目。参阅[打开 MVR 文件](opening-mvr-files.md)。

## 什么是 MVR / GDTF Inspector？它是只读的吗？

它可浏览项目快照或外部包、定义、资源和诊断信息，不修改项目或文件。参阅 [Inspector](inspector.md)。

## Perastage 可以下载 GDTF 吗？

可以，使用 **Tools → Download GDTF**，需要 GDTF Share 账户和网络连接。参阅[下载 GDTF](gdtf-download.md)。

## 可以离线浏览缓存的 GDTF 目录吗？

可以，前提是已有可用缓存。下载仍需在线认证。参阅[缓存浏览](gdtf-download.md#缓存与离线浏览)。

## 支持版面和 PDF 吗？

支持。制作可打印页面，并通过 **File → Print Layout...** 导出所选版面。参阅 [Layouts 与 PDF](layouts.md)。

## 日志在哪里？如何提供有效的问题报告？

使用 **Help → Open Logs Folder** 和 **Help → Export Diagnostic Report...**。附上复现步骤，分享前检查文件。参阅[故障排查](troubleshooting.md#日志与诊断报告)。

## 支持外部自动化吗？

OSC 和 MCP 是实验性本地集成，需要单独配置。参阅开发者[集成文档](https://github.com/PeramatoG/Perastage/blob/main/docs/developer/index.md)和 [MCP 适配器](https://github.com/PeramatoG/Perastage/blob/main/docs/developer/mcp_adapter.md)。日常内置命令见[快捷键与命令栏](shortcuts-and-command-bar.md)。
