# 下载 GDTF

使用 **Tools → Download GDTF** 从 GDTF Share 查找并下载灯具配置文件。在线加载目录和下载需要 GDTF Share 账户及互联网连接。

## 查找配置文件

1. 打开 **Tools → Download GDTF**。有可用缓存目录时会立即打开；否则需登录以加载目录。取消首次登录会取消操作。
2. 按制造商、灯具、UUID、修订版本或 DMX 模式名称搜索。所有搜索词都必须匹配，顺序不限；Manufacturer 和 Fixture 筛选器可缩小结果范围。
3. 选择修订版本，在下载前检查创建者、日期、大小、标识符以及各 DMX 模式的通道占用数。
4. 下载所选配置文件，并在项目或字典中检查灯具定义和模式。

## 缓存与离线浏览

新目录会复用一小时。过期缓存在后台刷新，浏览仍然可用；刷新失败时，缓存结果仍可使用。缓存浏览无需连接网络或登录。下载需要在线认证，并会等待正在进行的刷新完成。

下载失败或取消不会覆盖目标位置已有的配置文件。

## 凭据与本地配置文件

操作系统的安全凭据存储可用时，密码会存储在其中。运行时无法使用该存储时，Perastage 会提示，并可将凭据用于当前操作而不保存密码。之后的会话可能需要重新输入密码。用户名可以被记住，作为登录提示。

使用 **Tools → Edit dictionaries** 管理配置文件映射，使用 **Tools → Open user library folder** 查找本地内容。如果密码未保留，请参阅[凭据故障排查](troubleshooting.md#gdtf-share-凭据)。

## 在 MVR 导入期间解析配置文件

原有的 MVR/App/Download 来源对话框保持不变。选择 Download 后，队列会显示安全的
目录建议，以及可用的 MVR 或应用程序备用配置文件。选择一行可查看版本和兼容性警告，
已成功处理的行也可修改。**应用选择**会处理更改，然后由**确定**将结果应用于该类型的所有灯具。

**搜索 GDTF Share...** 使用现有的完整目录浏览器。**加载本地 GDTF...** 会验证文件并将其
复制到导入资源中，原始文件不会修改。请选择 DMX 模式，并检查型号、模式及通道占用数的差异。
同一行也可明确选择可用的备用来源。

MVR 自动关闭偏好设置仍默认为关闭，也可在队列内调整。启用时，已完成的安全选择会直接继续导入；
有歧义或失败的结果会保留供检查。取消会保留已完成的下载及有效的备用配置。
通道占用数相同并不保证 DMX 通道功能相同。

**应用选择**也会重试失败的下载。取消身份验证将停止剩余尝试，不会为每一行重复显示登录对话框。
