# 下载 GDTF

使用 **Tools → Download GDTF** 从 GDTF Share 查找并下载灯具配置文件。在线加载目录和下载需要 GDTF Share 账户及互联网连接。

## 查找配置文件

1. 打开 **Tools → Download GDTF**。有可用缓存目录时会立即打开；否则需登录以加载目录。取消首次登录会取消操作。
2. 按制造商、灯具、UUID、修订版本或 DMX 模式名称搜索。所有搜索词都必须匹配，顺序不限；Manufacturer 和 Fixture 筛选器可缩小结果范围。
3. 选择修订版本，在下载前检查创建者、日期、大小、标识符以及各 DMX 模式的通道占用数。
4. 下载所选配置文件，并在项目或字典中检查灯具定义和模式。

## 缓存与离线浏览

新目录会复用一小时。过期缓存在后台刷新，浏览仍然可用；刷新失败时，缓存结果仍可使用。缓存浏览无需连接网络或登录。下载需要在线认证，并会等待正在进行的刷新完成。

下载失败或取消不会覆盖目标位置已有的配置文件。

## 凭据与本地配置文件

操作系统的安全凭据存储可用时，密码会存储在其中。运行时无法使用该存储时，Perastage 会提示，并可将凭据用于当前操作而不保存密码。之后的会话可能需要重新输入密码。用户名可以被记住，作为登录提示。

使用 **Tools → Edit dictionaries** 管理配置文件映射，使用 **Tools → Open user library folder** 查找本地内容。如果密码未保留，请参阅[凭据故障排查](troubleshooting.md#gdtf-share-凭据)。

## 在 MVR 导入期间解析配置文件

原有的 MVR/App/Download 来源对话框保持不变。选择 Download 后，队列会显示安全的
目录建议，以及可用的 MVR 或应用程序备用配置文件。选择一行可查看版本和兼容性警告，
已成功处理的行也可修改。队列空闲时，**确定**保持可用：点击后会处理待应用的选择，并在完成后关闭窗口；分析和下载期间会禁用。新出现的失败或未解决选择会让窗口保持打开以供检查。不再有单独的应用按钮。接受的选择会应用于该类型的所有灯具。

选择 **Download** 后，只要灯具型号明确匹配，就会下载仓库文件，即使模式名称不同。例如，`DMX Mode` 不会阻止下载具有 `Basic` 和 `Compact` 模式的 ELP PAR。下载后会自动分配 DMX 模式，无需模式选择器或兼容性确认。优先使用 MVR 中指定的模式名称，忽略大小写、空格和标点；其次选择与原始配置通道数相符的唯一模式。若原始通道数未知，则可根据重复且相同的配接地址间距推断唯一模式。详情会说明使用的依据。

若模式仍有歧义，下载文件会保留，同时继续选用原始 MVR 配置和模式。行状态会解释原因；无需选择模式即可点击**确定**继续导入。**选择 DMX 模式...**仍可用于可选的手动调整。多个导入模式会被保留，不会合并为单一模式。

每行提供互斥的 **MVR**、**Perastage** 和**所选文件**复选框。不可用的来源会禁用。MVR 保留导入实例的模式；Perastage 使用可用的库配置；所选文件恢复上次下载或本地选择。切回已下载文件会复用已验证的包。**已下载；与原始 MVR 相同**表示两个文件的字节已完整比较并完全一致；相同名称或 FixtureTypeID 不能证明文件相同。

**搜索 GDTF Share...** 使用现有的完整目录浏览器。**加载本地 GDTF...** 会验证文件并将其
复制到导入资源中，原始文件不会修改。请选择 DMX 模式，并检查型号、模式及通道占用数的差异。
同一行也可明确选择可用的备用来源。

自动关闭仅在**偏好设置 → MVR Import/Export**中配置，默认仍为关闭。启用时，已完成的安全选择会直接继续导入；有歧义或失败的结果会保留供检查。

队列显示目录和登录活动、经过时间、按灯具类型计算的分析进度以及下载字节数。绿色表示下载、复用或本地选择成功；琥珀色表示使用原始 MVR 或应用程序备用配置；红色表示失败或未解析的配置。

候选项显示全部可用模式及其通道数。缺失的目录元数据会显示为不可用，而不是零通道，并在下载后根据实际包更新。详情显示导入模式及其已知通道占用数。配接推断要求同一全域中至少两个相等的相邻间距，且没有重复或无效地址，也没有其他类型的灯具穿插其间。它不会覆盖已知的原始通道数，也不会在通道数相同的多个模式间任意选择。间距可能包含空闲地址，相同通道数不保证相同的 DMX 功能。

**取消**、**Escape** 和关闭窗口会停止队列，并对该队列所有行使用原始 MVR 配置和模式继续导入。队列中的所有替换都会被舍弃，包括已完成的下载和本地选择。使用**确定**接受结果。

**确定**也会重试失败的下载。若希望在失败后继续使用原始配置，请选择其 **MVR** 来源，然后点击**确定**。取消身份验证会停止剩余尝试，不会重复显示登录对话框。
