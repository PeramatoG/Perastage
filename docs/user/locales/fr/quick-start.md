# Démarrage rapide

1. Utilisez **File → Import MVR...** pour [ouvrir un MVR](opening-mvr-files.md), ou créez un projet et ajoutez des éléments de scène. [Créer à partir de texte](create-from-text.md) permet de transformer une fiche technique en scène initiale.
2. Vérifiez le placement et l’orientation dans les [vues 2D et 3D](views.md).
3. Ouvrez éventuellement l’[Inspecteur MVR / GDTF](inspector.md), en lecture seule, pour examiner les archives et les définitions de projecteurs.
4. Consultez et modifiez les tables **Fixtures**, **Trusses**, **Hoists** et **Objects**. Vérifiez les types de projecteurs, modes DMX, patch et positions.
5. Enregistrez votre travail comme projet `.pstg` pour poursuivre l’édition plus tard.
6. [Exportez en MVR](opening-mvr-files.md#exporter-mvr) pour les échanges, ou préparez des [mises en page et PDF](layouts.md) pour l’impression et le partage.

Si des profils manquent, consultez [Téléchargement GDTF](gdtf-download.md). Les [Préférences](preferences.md) décrivent les unités et réglages d’import ; [Dépannage](troubleshooting.md) traite les problèmes d’exécution.
