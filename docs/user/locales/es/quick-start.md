# Inicio rápido

1. Utiliza **File → Import MVR...** para [abrir un MVR](opening-mvr-files.md), o crea un proyecto y añade elementos. [Create from text](create-from-text.md) permite generar una escena inicial a partir de un rider.
2. Revisa la posición y la orientación en las [vistas 2D y 3D](views.md).
3. Si lo necesitas, abre [MVR / GDTF Inspector](inspector.md), de solo lectura, para examinar el paquete y las definiciones de luminarias.
4. Revisa y edita las tablas **Fixtures**, **Trusses**, **Hoists** y **Objects**. Comprueba los tipos de luminaria, modos DMX, patch y posiciones.
5. Guarda el trabajo como proyecto `.pstg` para continuar editándolo después.
6. [Exporta MVR](opening-mvr-files.md#exportar-mvr) para intercambiar datos, o prepara [Layouts y PDF](layouts.md) para imprimir y compartir.

Si faltan perfiles, consulta [Descargar GDTF](gdtf-download.md). Consulta [Preferencias](preferences.md) para las unidades y la importación, y [Resolución de problemas](troubleshooting.md) para incidencias de ejecución.
