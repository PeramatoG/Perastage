# Preguntas frecuentes

## ¿Es Perastage un visualizador DMX en tiempo real?

No. Se centra en la edición de escenas, la revisión MVR y la documentación técnica. Consulta [Funciones](features.md).

## ¿Qué diferencia hay entre PSTG y MVR?

PSTG conserva el contexto del proyecto Perastage, layouts y símbolos para continuar editando. MVR intercambia datos de escena con otras aplicaciones. Consulta [Abrir archivos MVR](opening-mvr-files.md).

## ¿Qué plataformas de escritorio se admiten?

Windows, macOS y Linux. Consulta [Instalación](installation.md) y los paquetes disponibles para tu versión.

## ¿Puede Perastage importar y exportar MVR?

Sí, tanto abriendo un proyecto nuevo como fusionando con el actual. Consulta [Abrir archivos MVR](opening-mvr-files.md).

## ¿Qué es MVR / GDTF Inspector? ¿Es de solo lectura?

Permite explorar instantáneas del proyecto o paquetes externos, definiciones, recursos y diagnóstico sin modificar el proyecto ni el archivo. Consulta [Inspector](inspector.md).

## ¿Puede Perastage descargar GDTF?

Sí, mediante **Tools → Download GDTF**, con una cuenta de GDTF Share y acceso a la red. Consulta [Descargar GDTF](gdtf-download.md).

## ¿Puedo consultar el catálogo GDTF en caché sin conexión?

Sí, si ya existe una caché válida. Descargar sigue requiriendo autenticación en línea. Consulta la [consulta en caché](gdtf-download.md#consulta-en-caché-y-sin-conexión).

## ¿Se admiten layouts y PDF?

Sí. Prepara páginas imprimibles y exporta el layout seleccionado con **File → Print Layout...**. Consulta [Layouts y PDF](layouts.md).

## ¿Dónde están los registros? ¿Cómo comunico una incidencia útil?

Utiliza **Help → Open Logs Folder** y **Help → Export Diagnostic Report...**. Incluye pasos para reproducir el problema y revisa los archivos antes de compartirlos. Consulta [Resolución de problemas](troubleshooting.md#registros-e-informes-de-diagnóstico).

## ¿Hay automatización externa?

OSC y MCP son integraciones locales experimentales que requieren configuración independiente. Consulta la [documentación de integración](https://github.com/PeramatoG/Perastage/blob/main/docs/developer/index.md) y el [adaptador MCP](https://github.com/PeramatoG/Perastage/blob/main/docs/developer/mcp_adapter.md). Para comandos habituales integrados, consulta [Atajos y barra de comandos](shortcuts-and-command-bar.md).
