# Quick Start

1. Use **File → Import MVR...** to [open an MVR](opening-mvr-files.md), or start a new project and add scene elements. [Create from Text](create-from-text.md) can turn a rider into a starting scene.
2. Review placement and orientation in the [2D and 3D views](views.md).
3. Optionally open the read-only [MVR / GDTF Inspector](inspector.md) to examine package content and fixture definitions.
4. Review and edit the **Fixtures**, **Trusses**, **Hoists** and **Objects** tables. Check fixture types, DMX modes, patch and positions.
5. Save your work as a `.pstg` project so you can continue editing later.
6. [Export MVR](opening-mvr-files.md#export-mvr) for exchange, or prepare [Layouts and PDF](layouts.md) for printing and sharing.

If profiles are missing, see [GDTF Download](gdtf-download.md). See [Preferences](preferences.md) for units and import settings, and [Troubleshooting](troubleshooting.md) for runtime problems.
