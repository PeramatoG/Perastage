# Basic geometry primitives

Perastage can create basic 3D scene objects from the **Edit > Add Scene Object > Primitive** menu.

## Supported primitives

- Sphere
- Cube
- Cylinder

## Creation defaults

Each primitive creation dialog includes editable fields for the object name and dimensions before the object is added to the scene. Use **Save as Default** to store the current name and dimensions as the project default for that primitive type. Use **Load Default** to restore the saved project defaults into the dialog.

Primitive defaults are saved in the current project, so reopening the project restores the saved default name and dimensions for sphere, cube, and cylinder creation.

## Editing primitives

Double-clicking a basic primitive opens its edit dialog. The dialog lets you update the primitive name, dimensions, position, and rotation. Use **Apply** to apply the current values while keeping the dialog open, or **OK** to apply the values and close the dialog.

The **Save as Default** and **Load Default** buttons are also available while editing, so an existing primitive can become the new project default for future primitives of the same type.
